## Safe host-space unblock (manual, no broad deletion)

**Policy change authorized by the owner on 2026-10-09:** reduce the minimum free-space gate from **50 GiB to 5 GiB** in the runner guard, host audit and separate texture-proof workflow. The earlier 50-GiB denials remain valid historical failures. The 5-GiB setting is an **admission floor**, not an estimate that 43 frames, shaders, Unreal intermediates, checkout and rollback can fit in 5 GiB. Preserve original assets, native receipts, caches required by active jobs and checkout rollback safeguards. Do not use the broad-deletion `runner-space-recovery.yml` to free space.

**Deployment boundary:** `ACTIONS_RUNNER_HOOK_JOB_STARTED` points to the Windows host's local `scripts/runner/Invoke-YacsJobStarted.ps1`; that script loads `Assert-YacsDiskReserve.ps1` next to it **before checkout**. Merely pushing a new GitHub commit does not update the on-host script or its active process configuration. The operator must identify the *actual configured hook path*, verify its guard has the reviewed 5-GiB default, and safely synchronize the exact reviewed script while the runner is idle. Never bypass/disable the hook or overwrite a different live checkout. A repeat 50-GiB rejection is evidence the installed host guard is still stale.

On the Windows host, use PowerShell 7 and only the repository's allowlisted cleanup script:

```powershell
$script = 'D:\yacs\project\scripts\runner\Clear-YacsRunnerWorkspace.ps1'
$plan = & $script -RunnerRoot 'D:\yacs\runner' -MinimumAgeHours 24 -Json |
  ConvertFrom-Json
$plan.candidates | Sort-Object Bytes -Descending |
  Format-Table Name, Bytes, AgeHours, Path -AutoSize
"Estimated recoverable: {0:N2} GiB" -f ($plan.estimated_reclaim_bytes / 1GB)
```

Only after checking **every exact candidate path**, checking that the GitHub runner worker and Unreal processes are inactive, and confirming that no retained evidence or active build cache is targeted:

```powershell
& $script -RunnerRoot 'D:\yacs\runner' -MinimumAgeHours 24 -Apply `
  -ExpectedCandidateCount $plan.candidate_count `
  -ExpectedReclaimBytes $plan.estimated_reclaim_bytes
```

The script refuses changing candidates, reparse paths, active runner workers and active workspace-scoped Unreal processes. It can remove only eligible aged `Intermediate` and `DerivedDataCache` from inactive numbered Unreal worktrees. It does **not** authorize deleting original PNGs, Unreal source assets, accepted maps, LFS stores or retained proof folders. If the preview finds no eligible space, reclaim other genuinely disposable host files manually and recheck free space.
