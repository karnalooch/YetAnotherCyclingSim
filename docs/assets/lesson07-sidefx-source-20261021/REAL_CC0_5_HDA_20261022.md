## Height/visibility safety

Original HDA output on masked layers caused up to a **single float32 rounding unit** (~0.000030517578125 m) on 268 grass cells and 542 cliff/scree cells. The synthetic-only code was improved to quantify this deviation, allow restoration **only when maximum below 0.0001m and at most 5% of 65,536 samples**, and copy the **exact 256² source height float32 bytes** into a separate scratch `hou.Geometry`. It then compared all protected volumes including `height`, `mask`, `Alpha`, `grass_mask`, `sand_mask`, `cliff_mask`, `ramp_layer`; verified saved/reopened geometry equality; and fed the **corrected saved BGEO via a file node** into the next HDA, not the raw HDA result. No accepted source files or UE Landscape packages were modified.
